This project is an interactive website game created for the final assignment in my Humanities course on the history of science and technology. The goal of the game is to show how ideas of openness, secrecy, and authorship shaped early technical knowledge and how those ideas connect to engineering today.

The game is based on research from Pamela Long’s chapter “Openness and Authorship I,” which discusses how mining and metallurgy became formal disciplines through writing and knowledge sharing. The mechanics of the game are designed to reflect concepts from the research, such as the benefits of openness and the transformation of craft skills into written knowledge.
